# Responsive Design Tokens & Mobile-First CSS

A responsive dashboard styled only with modern CSS: custom properties (design tokens), CSS Grid and Flexbox.

## Features
- Design tokens in `:root` (colors, type scale, spacing, radii, shadows)
- Mobile-first grid with breakpoints at **320px, 768px, 1024px, 1440px**
- Glassmorphism (`backdrop-filter`), soft shadows, hover transitions
- Dark / light theme through CSS variables (remembers choice)
- Zero horizontal scroll (wide table scrolls inside its own card)

## Run
Open `index.html` in a browser. No build step.
